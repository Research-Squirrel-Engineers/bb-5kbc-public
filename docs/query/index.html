BB-5KBC: archaeological sites in Brandenburg, East Germany and West Poland around 5000 BC

Linked Open Data representation of some 540 archaeological sites in Brandenburg, East Germany and West Poland dating to around 5000 BC, with dating, cultural attribution, discovery events and georeferencing. The application ontology aligns with CIDOC CRM and its extensions CRMgeo, CRMsci and CRMarchaeo, with FSL for fuzzy statements and PROV-O for the provenance of the pipeline itself.

Every query below runs in your browser: the graph is fetched as a static Turtle file and queried with rdflib under Pyodide. There is no endpoint, nothing you type leaves your machine, and an archived copy of this repository stays queryable with no service to keep alive. The first page you open downloads roughly 10 MB of Python runtime; after that the browser has it cached.

  • The sites, on a map

    Every site with its cultural attribution. Any result carrying a coordinate is drawn on a map above the table, whatever else the query asks for — so an edit that adds a filter narrows the map with it.

    table and map 540 rows when built sites-on-a-map.rq

  • The cultural groups on a time axis

    Where each cultural group sits in time, and how many sites carry it. The Mesolithic bar spans four thousand years and dwarfs everything else: that is the record, not a drawing error.

    table and interval bars 9 rows when built culture-chronology.rq

  • What existed in a window of time

    Sites whose dating interval overlaps the window set by the two sliders. Move either one and the query re-runs: -4800 to -4750 gives 349 sites, -4400 to -4300 gives 472, -4100 to -3900 gives 296.

    table and map 411 rows when built time-slice.rq

  • How the sites were found

    The site type is known almost only where somebody excavated: stray finds and surface collections account for most of the record and leave the type unknown.

    table and bar chart 12 rows when built discovery-and-type.rq

  • How sharply each group is dated

    The width of the dating interval, per cultural group, against the number of sites.

    table and scatter plot 9 rows when built dating-precision.rq

  • How well each site is located

    The same points as the first map, coloured by the FSL confidence item instead of by culture: Q23 taken directly from the database, Q15 locatable to a district, Q24 only to a municipality centroid.

    table and map 540 rows when built locational-confidence.rq

  • Where the record hedges

    Values the source marked with a question mark are not quietly cleaned up in this dataset: they carry fsl:certaintyDesc "uncertain". These are the site types the excavator would not commit to.

    table and map 7 rows when built uncertain-attributions.rq

  • Sites per district, and how many are published

    Where the corpus is dense and where the literature is thin. A district with many sites and few publications is not necessarily under-researched — it may be that its excavations are reported in a form the source database…

    table and bar chart 82 rows when built literature-coverage.rq

  • Where the coordinates came from

    Every coordinate in this dataset was assigned by a georeferencing activity that records its own source. Provenance of the geometry, not of the site.

    table and bar chart 4 rows when built georeferencing-source.rq

  • German and Polish sites per cultural group

    The dataset straddles a modern border that means nothing to the fifth millennium BC.

    table and bar chart 14 rows when built cross-border.rq

  • Classes used, with counts

    What this collection actually contains — the counterpart to the void:classPartition statistics in the metadata. If the two disagree, the metadata is stale.

    table 33 rows when built classes-with-counts.rq

  • Sites via their CIDOC CRM superclass

    Checks that the alignment holds: the query asks for crm:E27_Site and is answered from bb5kbc:Fundstelle. This is what lets the collection be queried alongside other N4O collections that never heard of this ontology.

    table 1 rows when built sites-via-crm.rq

All of them on one page: all.html. The plain .rq files are in rq/, and the graph itself is bb5kbc-bundle.ttl (1.4 MB). The same queries are in metadata.ttl as sh:SPARQLSelectExecutable, where a harvester can read them.
